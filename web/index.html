    Scoring plays as a table

    Run: one team scores at least 7 points in a row while the other scores none. The run's player window starts right after the opponent's last score and ends with the run's last score, so it includes the stops, steals and misses that produced it.

    Game Score (Hollinger) = PTS + 0.4·FGM − 0.7·FGA − 0.4·(FTA − FTM) + 0.7·OREB + 0.3·DREB + STL + 0.7·AST + 0.7·BLK − 0.4·PF − TOV. EFF = (PTS + REB + AST + STL + BLK) − (missed FG + missed FT + TOV). Run windows rank only players with at least one recorded action inside the window; team rebounds and team turnovers are not credited to anyone.

    Minutes played are not in the play-by-play data, so the stats tab has no minutes column.
